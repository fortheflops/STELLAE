## Recipe
| Measurements | Ingredients               |
| :----------- | ------------------------- |
| 1 Cup                 | Peach Slices                           |
| 1                     | Orange                                 |
| $\frac{1}{2}$ Cup    | Powdered Sugar                         |
| $\frac{1}{2}$ Cup    | Peach Brandy                           |
| 1 bottle (~750ml)     | Dry Red Wine                           |
| $1 \frac{1}{2}$ Cups | Club Soda or Seltzer Water             |
| As needed             | Cracked Ice (for serving)              |
### Garnish
| Ingredients         |
| :------------------ |
| Orange slices       |
| Mint sprigs         |
___
### Instructions
1.  Prepare 1 C peach slices & 1 orange cut in 1/4" round slices.
2.  sprinkle with 1/2 C powered sugar.
3.  Allow sugar to soak in for about 1/2 hr.
4.  Add 1/2 C peach Brandy, 1 bottle dry red wine, 1 1/2 C Club soda or seltzer water.
5.  Serve over cracked ice.
6.  Garnish with the orange slices or mint sprigs.
