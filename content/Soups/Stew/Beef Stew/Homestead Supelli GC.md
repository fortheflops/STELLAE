## Author
Frank Bregante (January 1979)
___
## Recipe
| Measurements        | Ingredients                                        |
| :----------------- | :------------------------------------------------- |
| 1 Can                      | [[Homestead Supelli]] (or similar pasta)  |
| 2 Large Cans               | [[Tomato Sauce]]                          |
| 1                          | [[Beef Bouillon Cube]] or [[Stew Meat]]   |
| As Needed                  | [[Wine]] (for marinating)                 |
| 1                          | [[Carrot]], chopped                       |
| 1                          | [[Green Pepper]], chopped                 |
| 1                          | Mild [[Chili Pepper]]                     |
| 1.5 Cans                   | [[Ortega Chiles]] (diced)                 |
| 1                          | [[Onion]], chopped                        |
| 2 Cloves                   | [[Garlic]], minced                        |
| 2-3                        | [[Zucchini]] or Bitter Squash             |
| 1/2 pound                  | Fresh [[Mushrooms]]                       |
| 1 Can                      | [[Tomatoes]] (half whole, half halved)    |
___
## Instructions
1. If using stew meat, marinate it in wine for several minutes.
2. Combine all ingredients in a large pot.
3. Bring to a simmer and cook on low for 3-4 hours.
