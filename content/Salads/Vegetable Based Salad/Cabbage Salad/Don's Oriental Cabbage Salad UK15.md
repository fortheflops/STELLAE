## Recipe
| Measurements        | Ingredients                                        |
| :----------------- | :------------------------------------------------- |
| **For the Salad:** |                                           |
| 1 pound                    | [[Cole Slaw Mix]] (with carrots)          |
| 1 package                  | [[Ramen Oriental Noodle Soup Mix]] (Original flavor) |
| 1 bunch                    | [[Green Onions]], thinly sliced           |
| 1 package                  | Sliced [[Almonds]], toasted               |
| 1/2 cup                    | [[Sunflower Nuts]] (Optional)             |
| **For the Dressing:** |                                           |
| 3/4 cup                    | [[Olive Oil]] (or vegetable oil)          |
| 1 tablespoon               | [[Sesame Oil]]                            |
| 1 package                  | Seasoning packet from Ramen soup mix      |
| 1/3 cup                    | [[Sugar]]                                 |
| 1/3 cup                    | [[Vinegar]]                               |
| **For Chicken Salad Variation:** |                                   |
| 1 package                  | [[Tyson Breaded Chicken Breast Fillets]]  |
___
## Instructions
1.  **The night before:** Combine all dressing ingredients (olive oil, sesame oil, Ramen seasoning packet, sugar, and vinegar) in a jar or bowl. Stir occasionally.
2.  **Just before serving:** In a large salad bowl, combine the salad ingredients (cole slaw mix, green onions, toasted almonds, and optional sunflower nuts).
3.  Break up the block of uncooked Ramen noodles and add them to the salad.
4.  Pour the prepared dressing over the salad and toss to combine.
___

>[!Note]
>- For a **Chicken Oriental Salad** variation, add 1 package of Tyson Breaded Chicken Breast Fillets, cooked and sliced according to the directions on the box.
>- This salad is best when the dressing is made the night before and the salad is tossed just before serving.
