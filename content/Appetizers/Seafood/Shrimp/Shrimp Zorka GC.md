## Recipe
| Measurements        | Ingredients                                        |
| :----------------- | :------------------------------------------------- |
| Six                              | Large [[Shrimp]], Shelled                 |
| Four                             | [[Lemon Slices]] with peel                |
| Six                              | Pimento-Stuffed [[Olives]]                |
| One Tablespoon                   | [[Lemon Juice]]                           |
| Three Tablespoons                | Low-Calorie Italian [[Dressing]]          |
| $\frac{1}{2}$ Teaspoon           | Instant Granulated [[Garlic]]             |
| $\frac{1}{4}$ Teaspoon           | Dried [[Tarragon]]                        |
___
## Instructions
1.  In a bowl, mix all of the above ingredients together (lemon juice, Italian dressing, granulated garlic, tarragon) to create a marinade.
2.  Stir well. Add the shrimp, lemon slices, and olives to the marinade.
3.  Alternate olives, shrimp, and lemon slices on skewers.
4.  Broil for 3 minutes on each side.
5.  Baste with the remaining marinade while broiling.
