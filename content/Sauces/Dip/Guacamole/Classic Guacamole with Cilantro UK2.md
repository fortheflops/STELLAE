## Recipe

| Measurements | Ingredients               |
| :----------- | ------------------------- |
| 3                  | Ripe [[Avocados]]                       |
| 2                  | [[Tomatoes]], coarsely chopped          |
| 1                  | [[Red Onion]], finely chopped            |
| 1/2 Teaspoon       | Fresh [[Cilantro]] (Coriander), finely chopped |
| Juice of 2         | [[Lemons]]                              |
|                   | [[Salt]]                                |
|                   | [[Red Chili]]                           |
___
### Instructions
1. Peel and mash avocados.
2. Add tomatoes, red onion, and cilantro.
3. Toss mixture together lightly.
4. Sprinkle with lemon juice.
5. Season with salt and red chili.
