## Recipe

| Measurements | Ingredients               |
| :----------- | ------------------------- |
| 1/2 Pound           | [[Beef]]                        |
| 1/2 Pound           | [[Veal]]                        |
| 1/2 Pound           | [[Pork]]                        |
| 1                 | [[Egg]], separated              |
| 1 Cup             | [[Bread Crumbs]], soaked in [[Milk]] |
|                   | [[Onion]], grated            |
|                   | [[Salt]]                         |
|                   | [[Pepper]]                       |
|                   | Dry [[Bread Crumbs]]            |
| 1/2 Cup           | [[Sour Cream]]                  |
|                    | [[Butter]] or [[Fat]]         |
___
### Instructions
1.  Grind meat together.
2.  Add egg yolk, bread crumbs that have been soaked, grated onion, salt, and pepper and mix.
3.  Form into patties.
4.  Beat egg white.
5.  Dip patties in beaten egg white, then in dry bread crumbs.
6.  Saute in butter or fat.
7.  When brown, add sour cream and simmer only until cream is hot.
8.  Serve with new potatoes.
