## Recipe
| Measurements        | Ingredients                                        |
| :----------------- | :------------------------------------------------- |
| $\frac{1}{2}$ Pound              | Rolled [[Oats]]                           |
| $\frac{1}{2}$ Pound              | [[Rye Flakes]]                            |
| $\frac{1}{2}$ Pound              | [[Wheat Flakes]]                          |
| $\frac{1}{2}$ Pound              | Unroasted [[Wheatgerm]]                   |
| One Pound                        | [[Honey-Almond Crunch]]                   |
| Ten Ounces                       | Sliced [[Almonds]]                        |
| $\frac{1}{2}$ Pound              | Unsalted [[Cashews]]                      |
| $\frac{1}{2}$ Pound              | Shelled [[Walnuts]]                       |
| Two Pounds                       | [[Raisins]]                               |
| $\frac{1}{4}$ Pound (to taste)   | [[Brown Sugar]]                           |
| One to One & $\frac{1}{2}$ Pounds| [[Millet]]                                |
___
## Instructions
1.  In a very large bowl or container, combine all the ingredients: rolled oats, rye flakes, wheat flakes, unroasted wheatgerm, honey-almond crunch, sliced almonds, unsalted cashews, shelled walnuts, raisins, brown sugar (to taste), and millet.
2.  Mix thoroughly until all ingredients are evenly distributed.
3.  Store in an airtight container.
4.  Serve as a cold cereal with milk or yogurt.
