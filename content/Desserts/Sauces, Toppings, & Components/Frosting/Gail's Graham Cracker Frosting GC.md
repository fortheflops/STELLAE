## Recipe
| Measurements | Ingredients |
| :--- | :--- |
| $\frac{1}{2}$ Cup | Sweetened Condensed [[Milk]] |
| 2 Tablespoons | Melted [[Butter]] |
| 1 Cup | [[Powdered Sugar]] |
| 2 Tablespoons | Hershey's [[Cocoa Powder]] |
| $\frac{3}{4}$ Cup | Rolled [[Graham Cracker Crumbs]] |
| $\frac{1}{2}$ Cup | Chopped [[Walnuts]] |
| 1 Teaspoon | [[Vanilla Extract]] |
___
## Instructions
1.  In a bowl, mix together the **condensed milk**, melted **butter**, **powdered sugar**, and **cocoa powder**. A mixer can be used for this step to get it smooth.
2.  Stir in the **graham cracker crumbs**, **vanilla**, and chopped **walnuts** by hand.
3.  Check the consistency. If it's too dry, add a little more **milk**. If it's too runny, add more **crumbs** or **powdered sugar**.
4.  Spread on a warm cake for easier application.
___

>[!Note]
>"I make 1 & $\frac{1}{2}$ recipe -- if too runny can add more crumbs or powdered sugar. Add little more milk if too dry."
