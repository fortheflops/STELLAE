## Recipe
| Measurements          | Ingredients (Base)      |
| :-------------------- | :---------------------- |
| 4 tablespoons         | [[Butter]]              |
| 1 tablespoon          | [[Cream]]               |
| 1 teaspoon            | [[Vanilla Extract]]     |
| 3 cups                | [[Confectioners Sugar]] |
| **Flavor Options**    |                         |
| *For Lemon Icing*     |                         |
| 3 tablespoons         | [[Lemon Juice]]         |
| To Taste              | Grated [[Lemon Rind]]   |
| *For Orange Icing*    |                         |
| 3 tablespoons         | [[Orange Juice]]        |
| To Taste              | Grated [[Orange Rind]]  |
| *For Chocolate Icing* |                         |
| 2 ounces              | [[Chocolate]]           |
___
## Instructions
1.  Melt the butter in a mixing bowl.
2.  Stir in the cream, vanilla, and your chosen flavoring (lemon juice, orange juice, or melted chocolate).
3.  Gradually beat in the confectioners sugar.
4.  If making lemon or orange icing, add the grated rind.
5.  Beat until the icing is creamy and reaches a spreadable consistency.
6.  Spread on cake.
___

>[!Note]
>For the chocolate variation, use unsweetened or semi-sweet baking chocolate. The original recipe notes to "beat in" the chocolate after the butter is melted, so ensure it is melted and smooth before incorporating.
