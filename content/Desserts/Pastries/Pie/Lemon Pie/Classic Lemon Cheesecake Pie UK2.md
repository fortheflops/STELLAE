## Recipe

| Measurements | Ingredients |
| :--- | :--- |
| 1 (8in.) | [[Classic Graham Cracker Crust UK2]] |
| 3 (3oz) pkgs | [[Cream Cheese]], softened |
| 2 Tbsp | [[Butter]], softened |
| 1/2 C | [[Sugar]] |
| 1 | Whole [[Egg]] |
| 2 Tbsp | [[Flour]] |
| 2/3 C | [[Milk]] |
| 1/4 C | [[Fresh Lemon Juice]] |
| 2 Tbsp | [[Grated Lemon Peel]] |
___
### Instructions
1.  Preheat oven to 350°F.
2.  In a bowl, cream the **cheese** and **butter** together.
3.  Add the **sugar** and whole **egg** and mix well.
4.  Beat in the **flour**, then gradually add the **milk**.
5.  Stir in the **lemon juice** and **peel**.
6.  Pour the filling into the unbaked **graham cracker crust** shell. Sprinkle with extra crust crumbs if you have them.
7.  Bake for 35 minutes.
8.  Let cool, then chill thoroughly before serving.
